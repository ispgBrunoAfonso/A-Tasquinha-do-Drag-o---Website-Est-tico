## 🎯 Sobre Mim & Áreas de Atuação

O website destaca a minha paixão por tecnologia e marketing, focando-se em três pilares principais:
* **Social Media:** Gestão estratégica de redes sociais para aumentar o alcance e engajamento de marcas.
* **Tráfego Pago:** Criação e otimização de campanhas de anúncios (Meta Ads/Google Ads) para gerar conversões reais.
* **Marketing Digital:** Estratégias completas para posicionamento de marcas no mercado online.
